# Brick Bloom

Official support website and privacy policy for Brick Bloom by Abdulrauf.

Support: brickbloomsupport@gmail.com

## Publish with GitHub Pages

Settings → Pages → Deploy from a branch → main → / (root) → Save. GitHub displays the live URL after deployment. Privacy policy: privacy.html under that address.

Only public website files belong here. Game source and signing credentials remain separate.
